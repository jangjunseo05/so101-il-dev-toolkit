① 데이터 수집

실물 SO-101 리더암 → MuJoCo 팔로워암 텔레오퍼레이션 녹화 (run_teleop_real.py)

🔴 녹화 세션 제어
🔒 녹화는 실물 리더암을 USB로 연결한 컴퓨터에서만 할 수 있습니다. 실제 앱에서는 이 버튼이 MuJoCo 뷰어와 손목 카메라 미리보기를 띄우고, 뷰어 창에서 S 키로 녹화 시작·저장, X 키로 폐기합니다.
📋 녹화 가이드 — 성공률을 높이는 시연 방식
  • 같은 조건에서 반복: 물체는 매 episode 같은 위치에서 시작합니다(녹화 종료 시 자동 복귀). 팔도 매번 같은 시작 자세에서 출발합니다.
  • 멈추지 말고 한 번에: 잡기 → 들기 → 옮기기 → 놓기를 머뭇거림 없이 이어서 시연합니다. ACT는 지금 보이는 장면만으로 다음 동작 묶음을 예측하므로, 멈춘 구간이 섞이면 같은 장면에 "계속 멈춤"과 "진행" 정답이 섞입니다.
  • 비슷한 경로와 속도로 반복합니다.
  • 실수한 episode는 X로 버립니다.
  • 목표 수량: 최소 50개 이상.

코드 구조

run_teleop_real.py는 실물 리더암(SO101Leader)의 관절각을 50Hz로 읽어 MuJoCo 팔로워암에 전달하고, 30Hz로 손목 카메라 프레임과 관절값을 LeRobotDataset(v3.0)에 녹화합니다.

함수역할
load_or_create_dataset()기존 데이터셋 로드 또는 신규 생성 (비어 있는 데이터셋은 자동 백업 후 새로 만들고, 손상 의심 시에는 사용자 확인 후에만 백업)
leader_action_to_radians()리더암 실측 캘리브레이션 범위 → 팔로워 제어 범위로 비례 스케일링 (1:1 매핑 시 clip 문제 해결)
reset_pick_object()episode 종료 시 물체를 추론과 같은 위치로 복귀 (--randomize-object면 무작위 위치)
메인 루프리더 액션 읽기 → MuJoCo ctrl 적용 → 물리 스텝 → 30Hz 카메라 캡처·녹화

데이터 패킷 형태

keydtypeshape설명
actionfloat32(6,)6개 관절 목표값(라디안)
observation.statefloat32(6,)6개 관절 현재값(라디안)
observation.images.wrist_camimage(240, 320, 3)손목 카메라 RGB 프레임

코드 구조

메서드역할
compute_custom_stats()필드별 mean/std 계산 (다른 메서드들이 재사용)
detect_outliers()값 기준 z-score 아웃라이어 탐지 (관절별)
detect_outliers_delta()프레임 간 변화량 기준 z-score 아웃라이어 탐지 (episode 경계는 건너뜀)
check_integrity()NaN/Inf 스캔
get_clean_indices()위 결과의 합집합으로 '이상 없는' 인덱스 계산 (timestamp 제외, 비파괴적)
split_episodes()episode 단위 train/val 분할 (비파괴적, 인덱스만 계산)

이 데모의 QA 수치는 위 Python 메서드와 같은 계산을 브라우저에서 다시 구현해 낸 값입니다. 기본값(z=3)에서 Python 결과와 일치하는지 화면에 함께 표시합니다.

실제로 있었던 이상치 사례 — wrist_roll clip (이전 데이터)

20-episode 데이터에서 wrist_roll의 표준편차가 다른 관절보다 28배 작다는 것이 발견됐고, 진단 결과 리더암 실측 범위가 팔로워 모델 범위보다 넓어서 생기는 clip으로 판명돼 비례 스케일링으로 고쳤습니다 (수정 전 16/20 episode → 수정 후 0/28).

(자세히 보기) 코드 구조 — 관측 → 액션 루프 
MuJoCo에서 observation(qpos, 손목 카메라 렌더) 읽기
  → {"observation.state", "observation.images.wrist_cam"}
  → preprocessor(obs)          # 체크포인트의 정규화 설정 자동 적용
  → policy.select_action(obs)  # action chunking: 한 번 예측한 동작 묶음을 차례로 실행
  → postprocessor(action)
  → MuJoCo data.ctrl에 적용 (범위 clip 후 float32 유지)
